## User screenshot follow-up — 2026-10-21

The later screenshot at 07:37 shows the Spanish DNI template heading colliding: “REINO DE ESPAÑA” and “DOCUMENTO NACIONAL DE IDENTIDAD” are drawn into overlapping space. The header now measures both labels and fits each into a separate column. The same capture also showed the canvas and lower editor controls close to the Duo rail. Interactive editor surfaces add a gutter only while the system reports a vertical toolbar edge, which avoids a blank strip on conventional iPhones.

The Duo UI assertions now derive the reserved rail boundary from the live frames of the native Close and Export actions and keep a 12 pt gutter before it. The earlier `window.maxX - 80` heuristic was too indirect for this system-managed rail. These latest source changes still need the final simulator screenshot and UI run; the earlier 2026-10-21 capture documents the pre-follow-up appearance.
