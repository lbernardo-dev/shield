# Orden del set local

El orden comunica el flujo real de protección y evita una promesa de seguridad absoluta:

1. Revisa el documento escaneado antes de continuar.
2. Oculta los datos elegidos en el editor.
3. Comprueba la copia exportada.
4. Accede a la Bóveda privada.

Se excluyó Home porque el encabezado de biblioteca queda parcialmente bajo la barra de pestañas flotante en el primer viewport. Las capturas de Settings que demuestran el tema base permanecen en `raw/` como evidencia QA y no forman parte del set comercial. Los fixtures son sintéticos.
