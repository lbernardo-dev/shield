# MaskID

MaskID is a local-first document protection app for redaction, masking, secure export, and private storage.

## Review & feedback

The reusable, event-driven App Store review and private feedback system is documented in [Docs/REVIEW_FEEDBACK_SYSTEM.md](</Volumes/SSD Externo/DESARROLLO/iOS/MaskID/Docs/REVIEW_FEEDBACK_SYSTEM.md>). The product-specific event catalog is in [Docs/REVIEW_FEEDBACK_EVENT_MAP.md](</Volumes/SSD Externo/DESARROLLO/iOS/MaskID/Docs/REVIEW_FEEDBACK_EVENT_MAP.md>).

The system keeps Review and Feedback independent, uses RevenueCat as the Pro entitlement authority, uses StoreKit 2 for subscription status, and sends no document/OCR data in feedback telemetry.
